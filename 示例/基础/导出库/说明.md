# 反向 FFI —— 把 Qi 编译成 C 库供外部语言调用

`外部` 让 Qi 调 C；本示例做**反方向**：用 `导出` 关键字把 Qi 中文函数以 C ABI
导出成库符号，供 C / Rust / Go 等外部语言直接调用。

> 注意：本目录不进 `run_examples.sh`（它不是可执行 `.qi`），请按下面步骤手动构建。

## 导出语法

```qi
包 数学库;

// 默认用函数原名当 C 符号（clang/gcc/rustc 均接受 UTF-8 标识符，中文名可直接调用）
导出 函数 加法(a: 整数, b: 整数): 整数 { 返回 a + b; }

// 字符串往返：C 传 const char*，返回 char*（C 侧用毕 free()）
导出 函数 问候(名: 字符串): 字符串 { 返回 "你好, " + 名; }

// 显式指定干净的 ASCII C 符号名 —— 方便 Rust/Go 用 extern "C" 链接
导出 "qi_add" 函数 相加(a: 整数, b: 整数): 整数 { 返回 a + b; }
```

- C ABI 类型映射：`整数`↔`int64_t`、`浮点数`↔`double`、`布尔`↔`int64_t`(0/1)、
  `字符串`↔`const char*`(入参) / `char*`(返回)、`指针`↔`void*`。
- 导出函数体内可正常用 Qi 全部特性：ARC、异常、`选项<T>`、`打印行`、`启动`(goroutine) 等。
- 运行时在库加载时自动初始化（`@llvm.global_ctors` 构造器），C 侧**无需手动 init**。

## 构建

```bash
# 静态库(.a) + C 头文件(数学库对应 lib数学库.h)
qi compile --库 静态 数学库.qi -o lib数学库.a

# 动态库(mac .dylib / linux .so / win .dll)
qi compile --库 动态 数学库.qi -o lib数学库.dylib

# 自定义头文件路径
qi compile --库 静态 数学库.qi -o lib数学库.a --头 数学库.h
```

`--库` 也接受英文 `static` / `dynamic`。

## 从 C 调用

### 动态库（推荐，链接最省心）

动态库在构建时已把系统框架/运行时全部解析进去，C 端链接命令很干净：

```bash
qi compile --库 动态 数学库.qi -o lib数学库.dylib
clang test.c lib数学库.dylib -o test -Wl,-rpath,@executable_path
./test
```

### 静态库

静态库自包含全部 Qi 运行时**目标码**，但 macOS 上系统框架必须出现在最终链接行
（这是静态链接的通例，普通 Qi 可执行文件也一样链接它们）：

```bash
qi compile --库 静态 数学库.qi -o lib数学库.a
clang test.c lib数学库.a -o test \
  -framework CoreFoundation -framework Security \
  -framework SystemConfiguration -framework CoreServices -lpthread
./test
```

Linux 上静态链接需追加 `-lpthread -lm -ldl`。

预期输出：

```
加法(3, 4)     = 7
减法(10, 3)    = 7
问候("世界")   = 你好, 世界
qi_add(20, 22) = 42
qi_fib(10)     = 55

[OK] 所有断言通过
```

## 从 Rust 调用（`rust_test.rs`）

```rust
extern "C" { fn qi_add(a: i64, b: i64) -> i64; fn qi_fib(n: i64) -> i64; }
```

```bash
qi compile --库 动态 数学库.qi -o lib数学库.dylib
rustc rust_test.rs -L . -l dylib=数学库 -C link-arg=-Wl,-rpath,@executable_path -o rust_test
./rust_test
```

## 运行时能力演示（`运行时演示.qi` + `rtdemo.c`）

`运行时演示.qi` 在一个导出函数里同时用 `打印行` + `选项<T>` + `启动`(goroutine)，
证明库加载后运行时（协程调度 / ARC / IO）已完全就绪：

```bash
qi compile --库 动态 运行时演示.qi -o lib运行时演示.dylib
clang rtdemo.c lib运行时演示.dylib -o rtdemo -Wl,-rpath,@executable_path
./rtdemo   # qi_runtime_demo(8) → 8000
```

## 字符串所有权

返回 `字符串` 的导出函数：Qi 侧把结果 `strdup` 一份交给 C（**C 负责 `free()`**），
随后释放 Qi 自己的堆串。`strdup` 复制永不 UAF，反复调用不泄漏
（`stress.c` 跑 100 万次往返，RSS 稳定、无错误）。
